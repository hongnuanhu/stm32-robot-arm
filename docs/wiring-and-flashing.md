# 接线、烧录与调试

[项目首页](../README.md) · [实机演示](../media/robot-arm-demo.mp4)

本文记录双臂控制所用的引脚和上电检查。示教臂提供关节位置，STM32 采集后驱动执行臂上的舵机。

## 1. 接线

| 模块 | STM32F103C8T6 连接 |
| --- | --- |
| 示教臂电位器 | 五路滑动端信号依次接 `PA0`–`PA4` |
| 执行臂舵机 | 六路 PWM 信号依次接 `PA6`、`PA7`、`PB0`、`PB1`、`PB6`、`PB7` |
| OLED | `SCL → PB11`，`SDA → PB10` |
| ST-LINK | `SWDIO → PA13`，`SWCLK → PA14`，两端 `GND` 相连 |

电位器滑动端直连 ADC 时，信号电压应在 ADC 的参考电压范围内。舵机使用符合其规格的外置电源，舵机电源地与主控共地。先完成接线检查，再分别给主控和舵机供电。 [STM32F103C8 数据手册](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf)

## 2. 烧录

1. 保持舵机电源断开。在 Keil µVision 打开双臂控制工程，确认目标器件为 `STM32F103C8`。
2. 给主控供电。在工程选项的 **Debug** 页选择 **ST-Link Debugger**，进入 **Settings** 并把端口设为 **SW**。确认 Keil 能读到目标芯片 ID。
3. 按 **F7** 编译，确认没有编译错误。按 **F8** 下载，日志显示 `Verify OK` 后确认 `BOOT0 = 0`，并按主板的 **RESET**。 [Keil 下载说明](https://www.keil.com/support/man/docs/uv4cl/uv4cl_flash_programming.htm)

## 3. 联动检查

| 顺序 | 操作 | 观察点 |
| --- | --- | --- |
| 1 | 缓慢转动示教臂上的一个关节 | 对应通道的 ADC 读数随位置变化 |
| 2 | 接通舵机电源，小幅拨动一个关节 | 执行臂对应关节动作，方向和行程与机械结构匹配 |
| 3 | 依次试各关节，再组合动作 | 动作连续，各关节之间留有运动间隙 |

### 常见现象

| 现象 | 优先检查 |
| --- | --- |
| Keil 找不到目标芯片 | 主控供电、共地、SWDIO 和 SWCLK |
| 拨动示教臂时读数不变 | 电位器供电、滑动端与 ADC 通道的对应关系 |
| 有读数但执行臂不动 | 舵机独立供电、信号线顺序及共地 |
| 舵机持续抖动或主控复位 | 暂停动作，检查电源电压和关节是否卡滞 |
